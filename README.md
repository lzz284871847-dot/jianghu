# 江湖：万象 · 重制精简版 1.0.14

单机浏览器文字江湖。普通人起步，没有强制主线；先做自由探索、谋生、练武、交往与日常事件，省去完整社会和NPC账目模拟。面向iPhone浏览器，所有玩法由代码和固定内容数据驱动，不依赖生成式服务。

## 已实装
- 8个地点、相邻路线、白昼与天气。步行半小时，雨天山路一小时，移动不耗精力。
- 3种常驻约定与3种轮换采购：卸货、农具、草药、木料、鲜鱼、矿石；可接可放弃，有截止时间，没有固定主线。
- 打零工、采药、钓鱼、狩猎、打造、烹饪、制药、购买和出售。产出实际扣材料并记录库存；不核算每个买家的钱袋。
- 18项相关技能，经验上限依次100/200/400/600/800，自然跨阶段，没有固定等待天数。效果加成有限，成长缓慢。
- 4位有身份、性格、兴趣和眼下打算的NPC；按时间换地点，每日首次交谈增加关系，可向师傅学习吐纳、向医者学习基础制药。
- 6种独立日常事件，选择参与或离开；不参与也会在期限后自然结束。每日新闻区分可靠消息、街坊消息和未证实传闻。
- 基础交手、切磋、运功、防守、撤离。实战由玩家决定；切磋收手，实战死亡结束该角色，不自动读档。
- 精力、气血与恢复；不设饱食度、饮水。行动立即结算技能、时间、精力、钱财和物品。
- 按规则解析自由输入，例如“去码头”“钓鱼”“接码头卸货”“买铁料”。单项立即执行，多项先列行动计划；未知输入不会生成剧情或奖励。
- 本机自动保存、存档导入导出。旧版独立保留在legacy.html，旧存档键不改动；新版重新创建角色，不把旧版复杂状态混入新版。

## 范围
这是一座小镇和周边的第一版，没有完整古代社会模拟、婚育、门派系统、多人或金庸原作武学。人物背景目前不决定数值加成。关闭页面时世界时间不推进。存档存在当前浏览器，清理数据前请导出；本机存档不能防止玩家手动编辑或导入过去的记录。

## 开发与发布
`npm test`运行新旧版本测试；`npm run check`检查模块语法。`python3 -m http.server 8000`可在本机通过HTTP预览，不能用file://。
GitHub Actions在main更新后先测试，再部署index.html、legacy.html和src到Pages。旧版说明见LEGACY_README.md。

## 1.0.1 手机操作
固定底部导航分为江湖、人物、背包、消息、系统；人物资料与技能、背包与街市、存档设置分别在独立页面。行动结果直接显示在底部导航上方，可收起，长结算只在结果面板内滚动；切换栏目不会消耗时间或精力。街市提供进入买卖的快捷按钮。底部预留iPhone安全区，不覆盖页面末尾。存档格式和存档键不变。

## 1.0.2 NPC互动
按喜好赠礼，实际扣库存，每人每日一次，关系加2（封顶100）。向周师傅请教基础拳脚，每日一次，耗1小时、12精力、6文，拳脚经验加3；关系达到5时费用4文。沈医者关系达到10时诊金由8文减至6文。没有复杂NPC账目或人生模拟，旧存档补齐互动记录即可继续。

## 1.0.3 基础兵器
背包可换用空手、木棍、普通铁剑；木棍12文、铁剑24文。持有物品不会自动装备，换用耗5分钟、不耗精力；交手中不能换兵器。练习和实战分别结算拳脚、棍法或剑术，运功额外结算吐纳；请教师傅仍只练基础拳脚。木棍和铁剑仅增加1/2点基础伤害。旧存档保留拳脚经验，补齐棍法、剑术和剑库存；旧版已持有木棍的角色保留使用木棍。

## 1.0.4 轻量探索偶遇
沿路探索仍有55%概率平安走过、20%概率发现拦路人；另有12%路边常见药草、10%扭伤脚的旅人、3%遗落的3文钱袋。每个游戏日最多出现一次非战斗探索偶遇，参与或不参与都算一次；后续探索仍可能遇到拦路人，不因此得到剧情保护。选择实际扣时间、精力和物品，采药或搀扶才结算对应练习。纯粹给药、拾钱或登记招领不赠无关经验。忽略的偶遇次日会有独立后续消息。没有秘籍、强力装备或隐藏主线。

## 1.0.5 战斗与伤势反馈

气血100无伤、70–99轻伤、30–69中伤、1–29重伤；中伤出招威力降低10%，重伤降低20%。治疗和休息恢复气血后，伤势随之改善。出招扣除本次精力后不足20，威力降低40%，与伤势相乘；防守会明确记录挡下和承受的伤害，不增加无关武学经验。精力不足的出招按钮禁用，撤离仍可使用。绕开拦路人只花半小时，不扣精力；交手撤离仍是需要体力的战斗行动。没有新增骨折、内伤或残疾模拟。原存档继续使用。

## 1.0.6 自采原料与手艺闭环

竹林拾柴整理木料（2小时、12精力，基础成功率80%，成功木料2）；南山坡浅层采矿（2小时、20精力，需铁制工具，基础成功率65%，成功铁矿石1）。工具可在街市花20文购买或自行打造，采矿不消耗工具，暂不模拟耐久。精力扣除后不足20，采集成功率乘75%；相关技能练习基础经验2，疲劳时1，失败不送材料。作坊用铁矿石2与木料2炼成铁料2（2小时、18精力，锻造经验2）；铁料2与木料1再打造工具，出售或交付现有委托。采集、采矿只成长相关技能，炼铁和打造只成长锻造。沿用生产库存结算和疲劳失败规则；移动仍不耗精力，旧存档新增技能和矿石库存从零补齐。

## 1.0.7 轻量行动计划

自由行动输入多项命令，以分号、顿号、逗号或换行隔开，最多8项，每项40字。先列出计划，点击“执行计划”按原顺序执行；每项依旧由现有规则核算时间、路径、营业时间、精力、材料和经验，显示各项独立结算。遇到待决定事件、交手、无法执行的行动或跨日，立即暂停；失败项不扣资源、不移出计划，后续安排保留。支持跳过第一项和清空，均不消耗资源。跨日需查看世界消息后手动继续，不在后台推进、不代选事件、不自动寻路或替玩家买料恢复。每完成一项自动保存，计划进入原存档，旧存档补空计划。单项输入仍立即行动。

## 1.0.8 作坊配方与自制兵器

作坊集中显示全部配方、产出、耗时、精力、所需/现有材料、技能门槛与相关练习；缺料、缺精力或技能未达门槛时禁用制作按钮，文字说明原因，疲劳制作前提示20%失误风险。新增木工：木料2制作木棍1（2小时、14精力，木工经验2）；新增普通铁剑配方：铁料4与木料1锻造铁剑1（4小时、32精力），需要锻造Lv2（累计100经验），仅增加锻造经验2。兵器进入库存，需要主动装备；制作不增加棍法、剑术或拳脚。沿用材料结算、疲劳失败与封顶规则，可通过自由输入或行动计划制作。旧存档补齐木工经验0。

## 1.0.9 离线试玩

首次联网打开，等待系统页显示“离线文件已就绪”；随后游戏页面和实装模块可以离线加载，行动、世界时间和存档仍在本机执行。离线壳按版本完整预缓存后启用，升级只删除本游戏旧版本缓存；系统页可主动检查更新，下次打开加载更新后的页面。不缓存旧版入口、不上传玩家存档。缓存准备失败时仍可联网玩，不会误报准备完成。清理网站数据会删除存档和缓存，请先导出。iPhone用Safari分享菜单添加到主屏幕，按系统选项打开为网页App；主屏幕与浏览器存储如隔离，通过存档导出/导入转移角色。该流程不需要Mac，实际主屏幕安装仍需在iPhone上确认。

## 1.0.10 每日采购委托

常驻的卸货、农具、草药约定继续保留；另增一份按日轮换的普通采购：第一日村里收柴（木料3、8文），第二日船家收鱼（鲜鱼2、12文），第三日作坊收矿（铁矿石2、10文），之后循环。只在刊出日接新采购，但已接约定在三日截止前仍可交货；也可放弃。每项每天最多完成一次，交货统一半小时、2精力、经商经验1，库存实扣，不另送采集或武学经验。当前约定显示所需与现有材料，次日世界新闻和动态待办提示当天采购。无人参与的订单由买家自行寻找货源，不生成强制剧情。同步离线缓存；离线完整性测试读取项目版本，避免升级后沿用旧版本断言。

联网打开页面优先读取新页面；版本不匹配的模块必须联网读取，避免旧缓存冒充新版逻辑。断网时使用完整当前缓存。升级前已打开的页面不强制刷新；检查更新完成后重新打开，原存档保留。

## 1.0.11 重击与防守蓄势

每段交手仍耗时一分钟。普通出招耗4精力，重击耗8、威力为1.5倍，基础命中率75%；对应武学每高一级增加3个百分点，最高增加12个百分点。扣除本次精力后不足20，重击命中率乘80%；重伤再乘80%，同时沿用已有疲劳与伤势伤害衰减。防守耗4精力、减伤5（至少仍受1点），并为下一次出招提供基础伤害+2、重击基础命中率+10个百分点，总基础命中率最多95%。架势不叠加，出招或重击落空均消耗，撤离/结束后消失。普通出招和重击只增加所持兵器技能练习1，重击落空仍是相关发力练习；运功另结算吐纳，防守与撤离不增加无关经验。按钮展示当前重击命中率，缺精力禁用，撤离仍可用。旧存档架势缺省无加成，新架势可保存继续。同步离线缓存。

## 1.0.12 地图远行计划

地图邻近地点仍直接步行；点击远处地点，按当前天气计算路线并列出相邻移动计划，先预览再点击执行。每段独立花费30分钟，雨天前往城外小路、南山坡或竹林时60分钟，所有移动精力为0。路线不瞬移，不跳过途中事件；遇事、交手或跨日使用已有计划暂停规则，未走完的路线随存档保留。已有未完成计划时不覆盖；天气变化或先做别的行动后，实际时间和可走路线以执行时为准。当前委托增加安排前往交货地点的按钮，抵达不会自动交货或扣材料。路线算法只读地点数据，不改变NPC或经济模拟。同步离线缓存。

## 1.0.13 普通药膏与制药

与在场的沈医者交谈，可学习基础制药，不凭交谈增加制药经验。河湾村药炉用草药2、木料1调制普通药膏2（1小时、10精力，制药经验2）；疲劳时沿用20%失误、材料照扣、练习经验减半的规则。使用一份药膏花15分钟，恢复35气血，不恢复精力、不增加经验；满血不消耗。街市买8文、卖6文，出售只结算经商练习。原料、产出、库存与相关成长全部实算。村中药炉只显示药膏配方，作坊继续保留原配方；没有新增病症或药品神效。新增制药技能与学习标记、药膏库存，旧存档均补零/未学并保留原材料。自由输入和行动计划支持制药与用药膏，战斗中仍需先处理交手。同步离线缓存。

## 1.0.14 狩猎与烤肉干粮

简易猎具可在街市花12文购买，或在作坊用木料2、铁料1制作（2小时、14精力，木工练习2）。南山坡布置猎具、等候并收取合计3小时、20精力，基础成功率60%，成功得到猎物肉1；失败没有材料，仍有狩猎相关练习2。每升一级成功率增加2个百分点；扣除精力后不足20，成功率乘75%，经验减半。重伤气血低于25不能做这项重活。猎具可重复使用，不新增耐久或动物种群模拟。猎物肉街市卖6文，只结算经商；或在作坊加木料1做成干粮2（1小时、8精力，烹饪练习2）。沿用缺料不扣、疲劳制造失败、库存记录、经验封顶和行动计划。原存档补齐狩猎经验0、猎具和肉库存0，保留历史技能材料。同步离线缓存。
