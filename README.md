# 江湖

原创古代江湖单机文字 RPG，精简版 v0.2。普通人起步、无强制主线。无需账号或服务器，适配 iPhone 浏览器。

## 已实现
- 8 个地点，自由移动、打工、买卖、采药、住宿。
- NPC 按游戏时间更换地点，交谈增加关系并可学习吐纳。
- 基础拳脚、吐纳修炼、回合制战斗、切磋、撤离和倒地救助。
- 每次行动自动保存，本机存档导入/导出、数值校验。
- 世界时间随行动推进；关闭游戏时不模拟离线世界。

## 开发
Node.js 22 或更新版本：`npm test`、`npm run check`。
预览：`python3 -m http.server 8000`，打开 http://localhost:8000 。
使用 ES modules，应通过 HTTP 访问，不能直接打开 file://。

## GitHub Pages
在 Settings → Pages 选择 GitHub Actions。main 更新会先测试，再上传并部署 index.html 与 src。
私有仓库能否启用 Pages 取决于 GitHub 账户方案；保持私有，不自动改为公开。
只有部署成功且实际访问验证后，才将网址视为已发布。

## 限定范围
尚无多人、门派体系或金庸原作内容。后续按独立模块扩充。
本机存档属于浏览器与网址；清理网站数据可能丢失，请导出备份。

## 第一批 v0.2
角色年龄、性别、性格与小幅天赋属性；独立精力、饱食与饮水；年月日（每月30日、每年360日）；统一技能经验及100点阶段上限；作坊材料购买、药粉/工具/干粮生产；立即显示精力、金钱、物品变化。旧存档迁移时旧拳脚和吐纳经验超过100的部分封顶为100。

目前技能只有基础阶段，满额后不再增长；高级阶段后续开放。性格已记录，关系影响尚未实装。世界自主事件、每日新闻、完整伤病与永久死亡属于后续批次；现有倒地救助机制暂时保留。年龄随游戏年份增长。关闭网页不推进时间。
