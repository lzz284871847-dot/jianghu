# 江湖

原创古代江湖单机文字 RPG，精简版 v0.6。普通人起步、无强制主线。无需账号或服务器，适配 iPhone 浏览器。

## 已实现
- 9 个地点，自由移动、打工、买卖、采药、住宿。
- NPC 按游戏时间更换地点，交谈增加关系并可学习吐纳。
- 基础拳脚、吐纳修炼、回合制战斗、切磋、撤离和倒地救助。
- 每次行动自动保存，本机存档导入/导出、数值校验。
- 世界时间随行动推进；关闭游戏时不模拟离线世界。

## 开发
Node.js 22 或更新版本：`npm test`、`npm run check`。
预览：`python3 -m http.server 8000`，打开 http://localhost:8000 。
使用 ES modules，应通过 HTTP 访问，不能直接打开 file://。

## GitHub Pages
在 Settings → Pages 选择 GitHub Actions。main 更新会先测试，再上传并部署 index.html 与 src。
私有仓库能否启用 Pages 取决于 GitHub 账户方案；保持私有，不自动改为公开。
只有部署成功且实际访问验证后，才将网址视为已发布。

## 限定范围
尚无多人、门派体系或金庸原作内容。后续按独立模块扩充。
本机存档属于浏览器与网址；清理网站数据可能丢失，请导出备份。

## 第一批 v0.2
角色年龄、性别、性格与小幅天赋属性；独立精力、饱食与饮水；年月日（每月30日、每年360日）；统一技能经验及100点阶段上限；作坊材料购买、药粉/工具/干粮生产；立即显示精力、金钱、物品变化。旧存档迁移时旧拳脚和吐纳经验超过100的部分封顶为100。

技能阶段见最新v0.6说明，满额后必须主动进修才能继续增长。性格影响每日首次交谈的关系增长。完整伤病与永久死亡属于后续批次；现有倒地救助机制暂时保留。年龄随游戏年份增长。关闭网页不推进时间。

## 第二批基础 v0.3
每天结算天气、粮铺供需库存、干粮价格和三位NPC钱财；每日新闻来自这些实际变化。世界事件“商队货车陷泥”不需要玩家触发，跨日模拟可产生，次日自行处理；遇到时暂停耗时行动并提供帮忙、报信、离开。待办建议根据精力、饮食、库存、天气和事件动态生成。雨天去户外路程为两小时，移动仍不扣精力。

这只是小规模日常世界模拟；尚无婚育、死亡、完整NPC人生、门派兴衰或大地图。仅已实现的实际变化会作为可靠消息，不补写未发生的门派新闻。

## v0.3.1 简化生活
移除饱食度、饮水及其惩罚，旧存档迁移时删除对应字段；干粮继续用于恢复精力和气血。

## v0.4 NPC基础互动
五位NPC拥有年龄、性格、工作、家庭背景、兴趣、目标、能力和礼物喜好；这些资料可在人物栏展开查看。年龄与游戏年份推进，仍使用既有作息。新增沈医者、农户许成及各自每日收支。每天首次交谈增加关系，性格相同略有加成；重复交谈不刷关系。赠礼实际扣库存，每人每天一次。医者在场时可花6文恢复至多50气血，费用记入医者钱财。家庭与目标目前是人物背景资料，尚无婚育或目标决策AI。

## v0.5 生活职业收益
作坊购买钓竿，河边钓鱼；收获受技能、疲劳和随机概率影响，失败仍消耗时间与精力并结算练习经验。粮铺掌柜收购鲜鱼，村里的医者收购药粉，农户收购工具；交易实际转移钱财、扣除玩家库存，买家不在场或钱财不足时不能成交。新增鲜鱼烹饪，消耗鱼和木料制作干粮。旧存档自动补齐钓鱼技能、鱼和钓竿字段。移动继续只消耗时间，没有饱食度或饮水系统。

## v0.5.1 行动与成长核验
- 战斗每回合（含撤离）推进一分钟；旧存档默认分钟为0。出拳练拳脚，运功同时练拳脚和吐纳，各加1点，获胜不重复发经验；防守与撤离没有对应技能，不凭空加经验。疲劳降低攻击效果。
- 普通购买不增加经商经验，成功出售才结算经商。采药失败结算搜索练习，实际采到药材才增加药材辨识经验。采药技能小幅影响收获概率。
- 锻造、制药、烹饪按行动结束后的精力余量判断疲劳失误风险，少于20时20%概率失败；失败仍耗材料并记录练习。经验效率也按行动扣除精力后的余量降低，取整后单次有意义练习至少1点，阶段上限仍100。
- 生产单独列出材料消耗及剩余库存；气血变化立即显示。无需恢复时不消耗食物、草药或药粉。技能满额不继续增长，不重复打印加零。
这些是精简版基础熟练度规则，尚无门派高级武学或完整伤病体系；一次战斗回合代表一小段交手，不是一拳耗时一分钟。

## v0.6 技能阶段进修
12项已有技能统一支持Lv1–Lv3，经验上限分别100/300/600。满额不自动升级，出现“进修”行动，主动选择后消耗4小时、12精力和费用（升Lv2需12文，升Lv3需24文）。第一阶段需入世满30日，第二阶段需上次进修后满90日。进修必须去对应地点；拳脚和吐纳需周师傅在场，经商需粮铺掌柜在场。武学与经商的费用实际记入对应NPC钱财，生活技能费用视为研习耗材。进阶只开启新的练习阶段，不立即送经验、装备或武学。
新阶段经验从0开始，已有积累保留在效果计算中，攻击与采集收益有上限，防止突然变强。旧存档保持原经验并补齐Lv1阶段信息。Lv3满额后停止成长，后续阶段暂未开放。
