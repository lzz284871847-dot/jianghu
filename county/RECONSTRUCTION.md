# 青河县：生活与冒险体验重构

目标：普通人在自由、可信、充满未知的县域江湖里生活。生活与冒险并重，不设天命身世或强制长主线。验收看真实游玩体验，不看版本、代码量或系统数量。

## 已核实的起点（2026-10-20）

- main：bef10b848638130d8096cd47cef85371f7e40084，v5.38.0，Pages部署成功。
- PR #137原始改动仅默认折叠行动列表；两组回归成功，核实时尚未合并。
- local-map.js / app.js已有16地点、真实在场NPC、相邻出口、人物服务映射；scene-art.js已有四类共享背景。仍是场景示意，不是各建筑精确对应的独立地图。
- practice-growth.js已有实际劳动/耗料制作/采集的分档经验及失败成长；机械课程与固定升级节奏的问题没有因此全部解决。
- county-life.js已有有限县境事件、期限、粮药价格及道路时间影响；commerce、livelihood、world-feedback已有经济/商路接口。尚未形成所有职业可感知的完整因果链。
- npc-simulation.js已有作息、工作、有限近期目标、关系、健康及行踪。不能据此宣称NPC已具备自主谋划、欺骗或自然主动合作的完整体验。
- “独立运行”优先指玩家未参与某事时，随着游戏时间流逝仍然推进；不新增后台服务，不宣称关掉浏览器后持续模拟已实现。

## 分批次实施与验收

| 顺序 | 具体改动 | 通过标准 |
| --- | --- | --- |
| 1 场景办事 | 接续#137，设施直接提供现有操作，手机服务面板，保留完整分类入口 | 16地点、在场人物、实际收费/工作/制作/采集、离开与风险优先、旧档、窄屏及离线验证 |
| 2 实际手艺与职业 | 定向检查现有木工订单/普通制作/课程，先选一条普通人能玩的事务链；按真实投入、难度、结果及既有瓶颈整合成长 | 真实普通开局，课程不成为唯一必经通道；失败有实际损耗和反馈，高级技能有现有可用成果；不只提高经验 |
| 3 可见的因果 | 选一条现有商路或供给事件，连接已有货源、价格、短工、NPC近况与护送/冒险 | 玩家不接任务也推进；在场景、货架、人物与消息中可看见同一原因的不同后果；安稳生活仍可继续 |
| 4 有利益的人物 | 复用有限目标、信任与同行，选现有NPC做主动合作/拒绝与后续反馈 | 真实作息、钱物与精力约束；关系和失信改变后续选择；不过度增加状态与文本 |
| 5 冒险生活闭环 | 复用消息、准备、同行、武学战斗、伤势、装备和有限副本 | 消息→准备→同行/独行→探索/交战/撤回→结果影响生活；可拒绝、可失败，有独特实物回报 |

每批只改直接相关文件，复用已有机制；美术只读，新增引用沿用资源清单。禁止几十年、多代婚育、衰老和继承等深层模拟，不恢复复杂全社会账目。优先修复已经观察到的可玩性问题。

## 交付流程

开发分支 → 相关自动回归与必要全量检查 → 移动端浏览器、存档兼容与离线检查 → 更新PR → 检查该提交的CI → 合并main → 检查对应提交部署 → 核对线上版本和操作 → 提供真实试玩链接。

浏览器模拟窄屏不等于iPhone/Safari实机。新增模块同步离线文件清单，发布同步页面与模块引用版本。只报告实际完成的改动；第一批交互改善不等于整体重构完成。
