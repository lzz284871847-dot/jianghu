# 青河县 v5.35.0 手机尺寸与存档验收

本批为现有功能收尾，不增加地图、技能、奖励或长期模拟。检验范围是隔离的Chromium浏览器，不是iPhone、Safari或PWA实机。

## 修复

- 输入与选择框统一16px；备份文本支持窄屏内查看与全选。
- 系统页新增主动查看可复制JSON备份，无法下载时可自行复制另存文件。离开系统页清空显示，重新打开读取当时进度；不自动创建备份或回档。
- 导出先校验当前存档，提示“已请求下载”，不把下载请求当作文件已保存。
- 导入确认前校验项目、格式、大小和永久死亡；实际写入再次校验当前人生。取消、校验失败和存储失败不替换旧进度，结果消息可见；成功导入显示反馈，保留原存档数据。
- 山林委托没有额外材料的步骤明确显示“不耗额外材料”，去除空分隔符。

## 实际自动检查

- `npm test`：1275/1275；语法检查、所有county模块检查、差异检查通过。
- `scripts/qinghe-mobile-review.mjs`：102项检查通过。320×812、375×812、390×812、430×812、568×320、390×240。末项只模拟短视口，不等于真实手机键盘测试。
- 五个主页面无横向溢出；长姓名、最高钱款、多技能、待付款事务、穿戴与耐久等使用隔离测试存档，不声称是普通人实际成长攻略。
- 实际操作可复制备份、全选、下载、确认取消、损坏存档、确认导入、刷新，以及死亡后拒绝活档；下载JSON与测试进度相同，无重复奖励或耐久恢复。
- 缺材料按钮禁用并显示原因，预览显示实际材料；短视口能关闭结果窗，关闭按钮不被底栏遮挡。
- 69个离线资源保持同步。

运行可选浏览器验收需Playwright及Chromium。默认导入`playwright`；可通过`QINGHE_PLAYWRIGHT_MODULE`与`QINGHE_CHROMIUM_PATH`选择现有测试运行时，不要求将浏览器依赖加入游戏发布包。
